Roblox UI toolkit

Interfaces written like a web page, rendered as Roblox UI.

Rauri parses HTML, applies a CSS cascade and box layout, and runs a small JavaScript runtime against a DOM. The result is drawn with Roblox instances in Studio and in script executors.

HTML and CSS

A parser, cascade and layout engine for the parts interfaces use: flex, grid, inline flow, media queries, absolute and fixed positioning, pseudo-elements and hover transitions.

A small JavaScript runtime

Classes, promises, generators, regular expressions and a DOM with events. Enough for panels, tabs and local state without embedding a browser.

Studio and executors

The published build is a single Lua chunk. It finds a GUI parent, protects the ScreenGui when an executor allows it, and keeps working when those APIs are absent.

Quick start

Three steps to a window.

  1. 01

    Load the build

    Fetch dist/rauri.lua with the loader, or bundle the repository into a single file for a game.

  2. 02

    Write the interface

    Pass HTML, CSS and JavaScript strings to Rauri.web.app. The editor exports the same shape.

  3. 03

    Run it

    The window mounts into a ScreenGui. On touch devices it takes the full viewport and rebuilds when the screen changes.

Minimal app 
local Rauri = loadstring(game:HttpGet(
  "https://raw.githubusercontent.com/sickletone/project-rauri/main/dist/rauri.lua"
))()

Rauri.web.app({
  title = "Panel",
  width = 420,
  height = 300,
  html = [[
    <h1>Session</h1>
    <button id="run">Run script</button>
  ]],
  css = [[
    body { padding: 18px; background: #0b0b0f; color: #f2f2f6; }
    h1 { font-size: 20px; margin: 0 0 12px 0; }
    button { background: #f2f2f6; color: #101014; }
  ]],
  js = [[
    document.getElementById("run").addEventListener("click", () => {
      rauri.notify("Running");
    });
  ]],
})
